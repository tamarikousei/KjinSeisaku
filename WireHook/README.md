# SKYLINE ANCHOR（スカイライン・アンカー）

ワイヤーを撃ってビルの間を振り子で飛び回る、2D ワイヤーアクションゲームです。（DxLib / C++）

## 起動のしかた
1. `WireHook.sln` を Visual Studio で開く
2. 構成を `Release` / `x64` にする（`Debug` でも動きます）
3. F5 で実行

DxLib は `C:\DxLib_VC` にある前提です。`x64\Release\WireHook.exe` をダブルクリックしても起動できます（`Assets` フォルダは自動で探します）。

## ルール
- 光の柱（ゴール）にたどり着けばステージクリアです。
- 穴に落ちる、トゲやノコギリに触れるとミスになります。旗（チェックポイント）から再開します。
- 水色に光るブロックの縁と、黄色のリングにはワイヤーが刺さります。灰色の金属ブロックには刺さりません。
- 照準の色の意味：水色＝刺さる、黄色＝リング、赤い×＝届かない・刺さらない。
- クリスタルを全部集めて、ミスを少なく、速くクリアするとランク S になります。

## ステージ（1人用・全9ステージ）
クリアすると次のステージが解放されます。

1. 夕焼けの摩天楼（チュートリアル）
2. ネオン・ナイト（金属ブロック・ノコギリ・壁ジャンプ）
3. 嵐の塔（ジップでの壁越え・天井回廊・遠い足場の連続スイング）
4. 夜明けのハーバー（動く足場・上下する足場）
5. 雪のビル街（崩れる床・ジャンプ台）
6. サイバー・ハイウェイ（点滅するレーザー）
7. 黄昏の鉄橋（すべての仕掛けの組み合わせ）
8. 雷鳴の摩天楼（高難度）
9. オーロラの頂（最終ステージ）

### ギミック
| 見た目 | 効果 |
|---|---|
| 動く足場 | 乗ると運ばれる。ワイヤーも刺さる |
| ひびの入った床 | 乗ると0.5秒で崩れ、3秒で元に戻る |
| 黄色いジャンプ台 | 乗ると大ジャンプ |
| 赤いレーザー | 点いたり消えたりする。点く直前に細い線で予告。点灯中に触れるとミス |

## 対戦モード（2人）
タイトルの「対戦モード」から遊べます。参加 → モード → ステージの順に選びます。

- **ワイヤーバトル**：1画面のアリーナで戦います（アリーナは3つ）。相手をトゲ・ノコギリ・レーザー・穴に落とすと1本です。先に決めた本数（1〜5本）を取った方が勝ちになります。
  - 攻撃の方法：ワイヤーを相手に当てて引き寄せる／ジップで相手に体当たり／上から踏みつける／高速でぶつかる
  - 攻撃を受けるほどダメージ％がたまり、吹っ飛びやすくなります
  - 1ラウンドは60秒です。時間切れのときは、ダメージの少ない方がそのラウンドの勝ちです
  - 2Pを **CPU** にできます（ロビーで C キー、またはパッドの X）
- **タイムレース**：画面を上下に分けて、同じステージを競争します（2人専用）。先にゴールした方の勝ちです。

## 3D 表示（2.5D）
遊び方は横スクロールのまま、見た目をすべて 3D で描いています（`Render3D` / `Stage3D` / `Background`）。
- カメラは真横から遠近法で映します。距離を調整して、ゲームが動く面（z=0）がちょうど 1280×720 に映るようにしてあります。そのため、照準・HUD・吹き出しなどの 2D の計算はそのまま使えます。
- 足場は奥行きのある箱です。窓・屋上・金属などの模様は、起動時にプログラムで 1枚のテクスチャ（8×8マス）に描いて作ります。ステージは16列ずつメッシュにまとめて描きます。
- 背景は奥行きの違う4層の 3D ビル群です。横にくり返して無限に続き、遠くは霧に溶けます。
- キャラクターはカプセルと球で組んだ 3D の体です。足もとには丸い影が落ちます。
- ノコギリ・リング・クリスタル・ゴールの輪・チェックポイント・トゲも 3D の形です。
- 発光レイヤーでは足場と建物を黒く描いて、後ろの光をさえぎります。窓明かりとネオンの縁だけが光ります。

## グラフィック
- モニターの解像度（このPCでは 1920×1080）で描画します。ゲームの座標は 1280×720 のまま、`SetTransformTo2D` で拡大して描いています。
- **画質**（オプション）：標準＝画面と同じ解像度／高＝内部 2560×1440／最高＝内部 3840×2160。高解像度で描いてから縮小するので（スーパーサンプリング）、輪郭がなめらかになります。
- ワールドは HDR（16bit 浮動小数点）のバッファに描き、自作のピクセルシェーダー（`Shaders/*.hlsl`）で仕上げます。
  - 6段階の HDR ブルーム（13タップで縮小 → テントフィルターで拡大）
  - ネオンの光で周りを照らすライティング
  - 太陽・月からの光の筋（ゴッドレイ）。足場の形で光をさえぎります
  - 衝撃波のゆがみ（ミス・攻撃・ジップ・クリア時）、高速移動中の放射ブラー、色収差
  - ACES トーンマップ、ステージごとの色味、ビネット、フィルムノイズとディザ
- シェーダーが使えない環境では、自動で以前の描画方式に切り替わります。
- **画面モード**：フルスクリーン（ボーダーレス）とウィンドウを、F11 か Alt+Enter で切り替えられます。
- シェーダーを書き換えたときは `Shaders\build_shaders.bat` を実行してください（Windows SDK の fxc.exe を使います）。

## 確認用の起動オプション
- `WireHook.exe -stage 4` … ステージ4から直接始めます。
- `WireHook.exe -vs b 0 cpu` … バトル（アリーナ1）を CPU 相手にすぐ始めます。

## ソースの構成（src/）
| ファイル | 役割 |
|---|---|
| main.cpp | 起動・メインループ |

| Player | 移動・ワイヤー物理（振り子）・当たり判定 |
| Avatar | 主人公の見た目（図形で描画、マフラーの揺れ） |
| GameScene | プレイ画面・HUD・ポーズ |
| MenuScenes | スプラッシュ・タイトル・ステージ選択・操作説明・オプション・リザルト |
| Save | 記録と設定の保存（save.dat） |
